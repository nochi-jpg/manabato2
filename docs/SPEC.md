# まなびバトル2（manabato2）仕様書 v0.3（下書き・OK前）

まなびバトル（nochi-jpg/manabi-battle ver 3.0.0／Canva版 4.0.0）の続編。完全新作として新しいリポジトリで作り、旧作のデータを引きつげるようにする。
問題は nochi-jpg/manabi-resource（小1〜6・6,497問）を使う。

## 0. 旧作からの引きつぎ
- 旧作の QR（形式3・4）を読みこんで、旧作のデータを全部引きつぐ
- 引きつぐもの：名前、ステータス、タイプ、コイン、アイテム、おきにいり、アチーブメント、称号、オーラ、背景、ボス討伐、塔の記録、すがた、せいかく、隠し称号、あいことば、技、通算ログイン日数など
- **リセットするもの：問題の進み具合**（まだ／復習まち／あと1回／卒業）。旧作と新作では問題がちがう（同じ問題は66問だけ）
- 引きつげるのは1人1回だけ（同じQRを何回も読ませない）→【提案・返事まち】
- 問題がリセットされて、旧作で育てた子がもう一度解いてステータスが上がっても、そのままでよい（上がり方は減らさない）

## 1. スタミナと練習ダンジョン（1人で遊ぶ時間を短くする）
| | 旧作 | 新作 |
|---|---|---|
| 1日にふえる量 | 100（ダンジョン2回分） | ダンジョン1回分 |
| ためておける量 | 2000（40回分） | 10日分（10回分） |
| 復習ダンジョン | スタミナなし | スタミナなし・回数制限なし（旧作と同じ） |
- 旧作の「育成ダンジョン」を「練習ダンジョン」に名前を変える
- スタミナの数字は「ダンジョン1回＝1」のように回数で見せる案（10/10 など）

## 2. 出題（学年）
- ゲームを始めるときに学年を聞く（1〜6年）
- 出す問題は「1つ下の学年＋その学年」。1年生は1年の問題だけ
- 教科は5教科のまま。1・2年の「せいかつA」は社会に、「せいかつB」は理科に入れる。英語は3年から。**1・2年生も英語あり。3年の英語の問題を出す**（3年生も3年の英語だけ）
- 学年はせっていでいつでも変えられる
- その2学年を解き終わったら「おさらい」（ステータスの上がり方は少なめ）
- 表記はリソースの漢字モード（その学年までに習う漢字だけ）
- 問題データは圧縮してHTMLに入れる（Canvaの10MBにおさめるため）

## 3. アイテムを増やす
- 旧作は101個（隠しアイテム1個をふくむ）。旧作の101個はそのまま残し、番号を変えずに後ろに足す
- 30個ふやして131個に。中身はこれから考える
